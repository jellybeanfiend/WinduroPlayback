    Local editing

    • Files are written only after selecting the project folder and granting permission.
    • GPX files are copied to tracks/<race-id>/. Existing files are not removed when metadata is removed.
    • New races inherit the currently selected race’s sync line as a placeholder.
    • Run python scripts/validate_tracks.py before committing changes.
    • This editor does not commit or push changes.
